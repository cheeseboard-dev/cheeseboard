# 기능 명세서 (Functional Specification)

**프로젝트:** 치즈보드 (CheeseBoard)
**작성일:** 2026-04-22
**최종 수정:** 2026-04-24
**상태:** 초안

---

## 1. 화면 구성 및 라우팅

| 경로 | 화면 | 설명 |
|---|---|---|
| `/` | 메인 페이지 | 인기 클립 피드 |
| `/search?q=&type=&sort=&channelId=` | 검색 결과 페이지 | 키워드·필터·정렬 결과 |

URL 파라미터는 현재 필터·정렬 상태를 반영한다. 공유 링크로 동일한 결과를 재현할 수 있어야 한다.

---

### 1.1 메인 페이지 (`/`)

**레이아웃**
- 상단: 로고 + 검색창
- 하단: 인기 클립 피드 (카드 그리드, 무한스크롤)

**상태별 동작**

| 상태 | UI |
|---|---|
| 초기 로딩 | 카드 스켈레톤 20개 표시 |
| 정상 | 클립 카드 그리드 |
| 추가 로딩 (스크롤) | 하단에 스피너 표시 |
| 목록 끝 | "모든 클립을 불러왔습니다" 문구 |
| 오류 | "불러오는 중 오류가 발생했습니다. 다시 시도해주세요." + 재시도 버튼 |

---

### 1.2 검색 결과 페이지 (`/search`)

**레이아웃**
- 상단: 검색창 (현재 검색어 유지)
- 필터 영역: `[전체 | VOD | 클립]` 탭 + 정렬 드롭다운 + 스트리머 드롭다운
- 결과 영역: 카드 그리드 (무한스크롤)

**상태별 동작**

| 상태 | UI |
|---|---|
| 검색 중 (최초) | 카드 스켈레톤 20개 표시 |
| 정상 | 검색 결과 카드 그리드 |
| 추가 로딩 (스크롤) | 하단에 스피너 표시 |
| 결과 없음 | "검색 결과가 없습니다" + 검색어 초기화 유도 |
| 목록 끝 | "모든 결과를 불러왔습니다" 문구 |
| 오류 | "불러오는 중 오류가 발생했습니다. 다시 시도해주세요." + 재시도 버튼 |

**검색어 초기화 동작**
- 검색창에서 검색어를 모두 지우고 Enter 또는 검색 버튼 클릭 시 → 메인 페이지(`/`)로 이동

---

### 1.3 영상 재생 모달

**클립:** 카드 클릭 시 모달 오버레이에서 iframe 재생

**VOD:** 카드 클릭 시 치지직 원본 페이지를 새 탭으로 즉시 오픈 (모달 없음)

> VOD는 치지직 공식 embed URL이 없으므로 사이트 내 재생을 지원하지 않는다.

## 2. 영상 카드 컴포넌트

모든 피드/검색 결과에서 공통으로 사용하는 카드 UI.

| 요소 | 상세 |
|---|---|
| 썸네일 | 16:9 비율, 우측 하단에 영상 길이 오버레이 (HH:MM:SS) |
| 뱃지 | VOD / 클립 구분 뱃지 (썸네일 좌측 상단) |
| 제목 | 2줄 이내, 초과 시 말줄임 (...) |
| 스트리머 | 프로필 이미지 + 채널명 |
| 조회수 | "12.3만 회" 형식 |
| 날짜 | "3일 전" 상대 시간 (7일 초과 시 "2026-04-15" 절대 날짜) |

**모바일 (< 768px)**
- 카드 그리드: 2열 고정
- 카드 내 조회수·날짜는 1줄로 축약 표시

## 3. 기능 상세 명세

### FR-01 인기 클립 피드

**위치:** 메인 페이지

| 항목 | 내용 |
|---|---|
| 기본 정렬 | 조회수 내림차순 |
| 대상 | 클립만 (VOD 제외) |
| 로딩 방식 | 무한스크롤 (최초 20개, 이후 20개씩 추가) |
| 초기 상태 | 검색어 없이 접속 시 자동 노출 |
| API | `GET /api/clips/popular` |

---

### FR-02 키워드 검색

**위치:** 검색창 (메인/결과 페이지 공통)

| 항목 | 내용 |
|---|---|
| 검색 대상 | 영상 제목 (VOD·클립 공통) |
| 검색 엔진 | Elasticsearch + nori 형태소 분석기 |
| 최소 입력 | 1자 이상 |
| 트리거 | Enter 또는 검색 버튼 클릭 |
| 결과 없을 때 | "검색 결과가 없습니다" 안내 문구 |
| 검색어 초기화 | 검색창 비우고 Enter → 메인 페이지로 이동 |
| API | `GET /api/search` |

> 태그는 현재 VOD에만 존재하며 클립에는 없다. 추후 클립 태그 지원 여부는 Phase 2 검토 사항.

---

### FR-03 스트리머 필터

**위치:** 검색 결과 페이지 필터 영역

| 항목 | 내용 |
|---|---|
| UI 형태 | 드롭다운 (스트리머명 입력으로 내부 검색 가능) |
| 선택 방식 | 단일 선택 |
| 초기 목록 | 페이지 진입 시 `GET /api/streamers` 호출로 전체 목록 로드 |
| 적용 범위 | 현재 검색 결과에 AND 조건으로 필터 적용 |
| URL 반영 | `?channelId=` 파라미터로 상태 유지 |
| 초기화 | "전체" 선택 시 필터 해제 |

---

### FR-04 정렬

**위치:** 검색 결과 페이지 필터 영역

| 옵션 | 기준 | URL 값 |
|---|---|---|
| 인기순 (기본값) | 조회수(`read_count`) 내림차순 | `?sort=popular` |
| 최신순 | 업로드일(`published_at` / `created_at`) 내림차순 | `?sort=latest` |

---

### FR-05 VOD / 클립 구분

**위치:** 검색 결과 페이지 (탭 형태)

| 탭 | 내용 | URL 값 |
|---|---|---|
| 전체 (기본값) | VOD + 클립 혼합 | `?type=all` |
| VOD | 다시보기만 | `?type=vod` |
| 클립 | 클립만 | `?type=clip` |

---

### FR-06 영상 재생

**위치:** 카드 클릭 시

**클립 재생 (모달)**

| 항목 | 내용 |
|---|---|
| 트리거 | 클립 카드 클릭 |
| 재생 방식 | 모달 오버레이 내 iframe 임베딩 |
| embed URL | `https://chzzk.naver.com/embed/clip/{clipUID}` |
| 모달 내 정보 | 제목, 스트리머명, 조회수, 업로드일 |
| 외부 링크 버튼 | "치지직에서 보기" → 새 탭 |
| 모달 닫기 | 외부 클릭 또는 X 버튼 |
| 모바일 | 모달 대신 전체화면에 가깝게 표시 (bottom sheet 또는 전체 오버레이) |

**VOD 재생**

| 항목 | 내용 |
|---|---|
| 트리거 | VOD 카드 클릭 |
| 재생 방식 | 치지직 원본 페이지를 새 탭으로 즉시 오픈 (모달 없음) |
| 이동 URL | `https://chzzk.naver.com/video/{videoNo}` |

> 클립: 치지직 공식 "동영상 퍼가기" 기능으로 iframe 임베딩 지원 확인.  
> VOD: 공식 embed URL 없음. 사이트 내 재생 불가, 외부 링크로 대체.

### FR-07 치지직 링크

**위치:** 클립 재생 모달 내

| 항목 | 내용 |
|---|---|
| VOD 링크 | `https://chzzk.naver.com/video/{videoNo}` |
| 클립 링크 | `https://chzzk.naver.com/clips/{clipUID}` |
| 노출 위치 | 재생 모달 내 "치지직에서 보기" 버튼 |
| 동작 | 새 탭으로 열기 |

### FR-08 검색 자동완성

**위치:** 검색창 (메인/결과 페이지 공통)

| 항목 | 내용 |
|---|---|
| 대상 | 스트리머명 |
| 트리거 | 2자 이상 입력 시 |
| 지연 | 300ms debounce |
| 표시 | 검색창 하단 드롭다운, 최대 5개 |
| 항목 구성 | 프로필 이미지 + 채널명 |
| 선택 시 | 해당 스트리머로 필터링된 검색 결과 페이지로 이동 (`/search?channelId=`) |
| 닫기 | 외부 클릭 또는 ESC |
| API | `GET /api/search/suggest?q=` (2자 미만 시 요청 안 함) |

### FR-10 네이버 로그인

**위치:** 헤더 우측 상단

| 항목 | 내용 |
|---|---|
| 방식 | 네이버 아이디로 로그인 (OAuth 2.0) |
| 진입 | 헤더 "로그인" 버튼 클릭 → 네이버 OAuth 인증 페이지로 리다이렉트 |
| 콜백 | 인증 완료 후 원래 페이지로 복귀 |
| 수집 정보 | 네이버 고유 ID, 닉네임, 프로필 이미지 |
| 로그인 후 헤더 | "로그인" 버튼 → 프로필 이미지 + 닉네임으로 교체 |
| 로그아웃 | 프로필 클릭 → 드롭다운에서 "로그아웃" 선택 |
| 세션 유지 | JWT (HttpOnly 쿠키). 만료 시 자동 로그아웃 |
| 비로그인 | 태그 기여(FR-12), 댓글(FR-11) 외 모든 기능은 비로그인도 사용 가능 |

---

### FR-12 사용자 태그 기여

**위치:** 영상 카드 하단 / 클립 재생 모달 내

**목적:** 사용자가 직접 태그를 붙여 검색 커버리지를 넓힌다. 추가된 태그는 Elasticsearch 인덱스에 즉시 반영되어 해당 영상이 관련 검색어에 노출되는 데 기여한다.

**태그 표시**

| 항목 | 내용 |
|---|---|
| 위치 | 클립 재생 모달 하단, VOD는 카드 하단 (공간 있을 때만) |
| 표시 형태 | 태그 칩(pill) 나열. 공식 태그(CHZZK 원본)와 사용자 태그를 같은 열에 표시 |
| 공식 태그 구분 | 스타일(색상/테두리)로 구분. 마우스 오버 시 "CHZZK 태그" 툴팁 |

**태그 추가**

| 항목 | 내용 |
|---|---|
| 진입 | "+ 태그" 버튼 클릭 → 인라인 입력창 노출 |
| 비로그인 | 클릭 시 "로그인이 필요합니다" 토스트 + 네이버 로그인 유도 |
| 입력 제한 | 최대 20자, 특수문자 제한 (한글·영문·숫자·공백만 허용) |
| 중복 방지 | 이미 존재하는 태그(공식 또는 사용자) 입력 시 "이미 있는 태그입니다" 안내 |
| 저장 | Enter 또는 확인 버튼 → 필터링 통과 후 DB + ES 인덱스 업데이트 |
| 태그 개수 제한 | 영상당 사용자 태그 최대 20개 (공식 태그 별도) |

**비속어·비하 표현 필터링**

| 항목 | 내용 |
|---|---|
| 1차 필터 (현재) | 서버에서 태그 저장 전 정규식 + 블랙리스트 검사. 초성 표기(`ㅅㅂ`), 특수문자 삽입(`시*발`), 공백 우회(`시 발`) 패턴 포함 |
| 차단 시 응답 | "사용할 수 없는 태그입니다" 안내. 저장 거부 |
| 추후 (미정) | LLM 기반 분류로 맥락적 비하 표현까지 탐지 범위 확장 예정 |

**검색 반영 방식**

| 항목 | 내용 |
|---|---|
| ES 필드 | `user_tags` (keyword + text 분석) |
| 검색 쿼리 | `multi_match` 대상에 `user_tags` 포함. 가중치는 제목 > 공식 태그 ≥ 사용자 태그 |
| 인덱스 업데이트 | 태그 추가/삭제 즉시 `POST /{index}/_update` 로 해당 document 부분 업데이트 |

**태그 삭제**

| 항목 | 내용 |
|---|---|
| 본인 태그 | 태그 칩에 × 버튼 노출 (본인이 추가한 태그에만) |
| 타인 태그 | 삭제 불가 (관리자 기능은 Phase 2 이후 검토) |
| API | `DELETE /api/videos/{videoNo}/tags/{tag}`, `DELETE /api/clips/{clipUid}/tags/{tag}` |
