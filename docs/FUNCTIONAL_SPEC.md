## 1. 화면 구성 및 라우팅

| 경로 | 화면 | 설명 |
|---|---|---|
| `/` | 메인 페이지 | 인기 클립 피드 |
| `/search?q=&type=&sort=&channelId=&category=` | 검색 결과 페이지 | 키워드·필터·정렬 결과 |

URL 파라미터는 현재 필터·정렬 상태를 반영한다. 공유 링크로 동일한 결과를 재현할 수 있어야 한다.

---

### 1.1 메인 페이지 (`/`)

**레이아웃**
- 공통 헤더: 로고, 보조 필터(정렬/스트리머/카테고리), 가운데 검색 바(타입 범위 선택 + 검색어 + 검색 버튼이 한 컨테이너), 로그인/프로필
- 하단: 인기 클립 피드 (카드 그리드, 무한스크롤)

**필터 조작 시 동작**
- 메인 페이지에서 헤더 필터를 변경하면 즉시 `/search?type=...&sort=...&channelId=...&category=...` 형태로 검색 결과 페이지로 이동한다. 검색어(`q`)는 비워둔 채로도 진입 가능하며, 필터만으로 결과를 볼 수 있다.

**모바일 헤더**
- 모바일에서는 헤더가 두 줄로 wrap되며 첫째 줄은 로고 + 검색창 + 로그인/프로필, 둘째 줄은 필터 영역을 가로 정렬한다. 필터가 너무 좁으면 `overflow-x: auto`로 가로 스크롤을 허용한다.

**상태별 동작**

| 상태 | UI |
|---|---|
| 초기 로딩 | 카드 스켈레톤 20개 표시 |
| 정상 | 클립 카드 그리드 |
| 추가 로딩 (스크롤) | 하단에 스피너 표시 |
| 목록 끝 | "모든 클립을 불러왔습니다" 문구 |
| 오류 | "불러오는 중 오류가 발생했습니다. 다시 시도해주세요." + 재시도 버튼 |

---

### 1.2 검색 결과 페이지 (`/search`)

**레이아웃**
- 공통 헤더: 로고, 보조 필터(정렬/스트리머/카테고리), 가운데 검색 바(타입 범위 선택 + 검색어 + 검색 버튼이 한 컨테이너), 로그인/프로필. 검색 바에는 현재 검색어를 유지한다.
- 결과 영역: 카드 그리드 (무한스크롤)

> 검색 결과 페이지의 별도 필터 영역은 공통 헤더로 통합한다. 메인 페이지와 검색 결과 페이지는 같은 헤더를 공유하며, 페이지별로 달라지는 영역은 결과 헤딩과 카드 그리드 등 본문 결과 영역이다.

**상태별 동작**

| 상태 | UI |
|---|---|
| 검색 중 (최초) | 카드 스켈레톤 20개 표시 |
| 정상 | 검색 결과 카드 그리드 |
| 추가 로딩 (스크롤) | 하단에 스피너 표시 |
| 결과 없음 | "검색 결과가 없습니다" + 검색어 초기화 유도 |
| 목록 끝 | "모든 결과를 불러왔습니다" 문구 |
| 오류 | "불러오는 중 오류가 발생했습니다. 다시 시도해주세요." + 재시도 버튼 |

**검색어 초기화 동작**
- 검색창을 비우고 Enter → 메인 페이지(`/`)로 이동. 단, 필터(`type`, `sort`, `channelId`, `category`)만 채워진 상태에서는 검색 페이지에 머물며 필터 결과를 표시한다.

### 1.3 영상 재생 모달

**클립:** 카드 클릭 시 모달 오버레이에서 iframe 재생

**VOD:** 카드 클릭 시 치지직 원본 페이지를 새 탭으로 즉시 오픈 (모달 없음)

> VOD는 치지직 공식 embed URL이 없으므로 사이트 내 재생을 지원하지 않는다.

## 2. 영상 카드 컴포넌트

모든 피드/검색 결과에서 공통으로 사용하는 카드 UI.

| 요소 | 상세 |
|---|---|
| 썸네일 | 16:9 비율, 우측 하단에 영상 길이 오버레이 (HH:MM:SS) |
| 뱃지 | VOD / 클립 구분 뱃지 (썸네일 좌측 상단) |
| 제목 | 2줄 이내, 초과 시 말줄임 (...) |
| 스트리머 | 프로필 이미지 + 채널명 |
| 조회수 | "12.3만 회" 형식 |
| 날짜 | "3일 전" 상대 시간 (7일 초과 시 "2026-04-15" 절대 날짜) |

**모바일 (< 768px)**
- 카드 그리드: 2열 고정
- 카드 내 조회수·날짜는 1줄로 축약 표시

## 3. 기능 상세 명세

### FR-02 키워드 검색

**위치:** 검색창 (메인/결과 페이지 공통)

| 항목 | 내용 |
|---|---|
| 검색 대상 | 영상 제목 (VOD·클립 공통) |
| 검색 엔진 | Elasticsearch + nori 형태소 분석기 |
| 최소 입력 | 1자 이상 |
| 트리거 | Enter 또는 검색 버튼 클릭 |
| 결과 없을 때 | "검색 결과가 없습니다" 안내 문구 |
| 검색어 초기화 | 검색창을 비우고 Enter → 메인 페이지(`/`)로 이동. 단, 필터(`type`, `sort`, `channelId`, `category`)만 채워진 상태에서는 검색 페이지에 머물며 필터 결과를 표시 |
| API | `GET /api/search` |

> 태그는 현재 VOD에만 존재하며 클립에는 없다. 추후 클립 태그 지원 여부는 Phase 2 검토 사항.

### FR-03 스트리머 필터

**위치:** 헤더 필터 영역 (메인/검색 공통)

| 항목 | 내용 |
|---|---|

| URL 반영 | `?channelId=` 파라미터로 상태 유지 |
| 초기화 | X 버튼으로 해제. 비움은 "전체" 의미 |

### FR-04 정렬

**위치:** 헤더 필터 영역 (메인/검색 공통)

| 옵션 | 기준 | URL 값 |
|---|---|---|
| 인기순 (기본값) | 조회수(`read_count`) 내림차순 | `?sort=popular` |
| 최신순 | 업로드일(`published_at` / `created_at`) 내림차순 | `?sort=latest` |

### FR-05 VOD / 클립 구분

**위치:** 검색 바 좌측 (검색 바와 같은 컨테이너 안에 통합된 컴팩트 드롭다운)

**시각:** 검색창 내부 segment처럼 보이도록 경계선은 은은하게 처리. 검색어와 함께 "검색의 범위(scope)"를 정한다는 의미를 시각적으로 전달.

| 옵션 | 내용 | URL 값 |
|---|---|---|
| 전체 (기본값) | VOD + 클립 혼합 | `?type=all` |
| VOD | 다시보기만 | `?type=vod` |
| 클립 | 클립만 | `?type=clip` |

### FR-08 검색 자동완성

**위치:** 검색창 (메인/결과 페이지 공통)

| 항목 | 내용 |
|---|---|
| 대상 | 스트리머명 |
| 트리거 | 2자 이상 입력 시 |
| 지연 | 300ms debounce |
| 표시 | 검색창 하단 드롭다운, 최대 5개 |
| 항목 구성 | 프로필 이미지 + 채널명 |
| 선택 시 | 해당 스트리머로 필터링된 검색 결과 페이지로 이동 (`/search?channelId=`) |
| 닫기 | 외부 클릭 또는 ESC |
| API | `GET /api/search/suggest?q=` (2자 미만 시 요청 안 함) |

> FR-08은 검색창 입력에 대한 자동완성이며, FR-03 스트리머 필터 자동완성은 헤더 필터 영역의 스트리머 입력란에서 트리거된다.

### FR-12 사용자 태그 기여

**위치:** 영상 카드 하단 / 클립 재생 모달 내

**목적:** 사용자가 직접 태그를 붙여 검색 커버리지를 넓힌다. 추가된 태그는 Elasticsearch 인덱스에 즉시 반영되어 해당 영상이 관련 검색어에 노출되는 데 기여한다.

**태그 표시**

| 항목 | 내용 |
|---|---|
| 위치 | 클립 재생 모달 하단, VOD는 카드 하단 (공간 있을 때만) |
| 표시 형태 | 태그 칩(pill) 나열. 공식 태그(CHZZK 원본)와 사용자 태그를 같은 열에 표시 |
| 공식 태그 구분 | 스타일(색상/테두리)로 구분. 마우스 오버 시 "CHZZK 태그" 툴팁 |

**태그 추가**

| 항목 | 내용 |
|---|---|
| 진입 | "+ 태그" 버튼 클릭 → 인라인 입력창 노출 |
| 비로그인 | 클릭 시 "로그인이 필요합니다" 토스트 + 네이버 로그인 유도 |
| 입력 제한 | 최대 20자, 특수문자 제한 (한글·영문·숫자·공백만 허용) |
| 중복 방지 | 이미 존재하는 태그(공식 또는 사용자) 입력 시 "이미 있는 태그입니다" 안내 |
| 저장 | Enter 또는 확인 버튼 → 필터링 통과 후 DB + ES 인덱스 업데이트 |
| 태그 개수 제한 | 영상당 사용자 태그 최대 20개 (공식 태그 별도) |

**비속어·비하 표현 필터링**

| 항목 | 내용 |
|---|---|
| 1차 필터 (현재) | 서버에서 태그 저장 전 정규식 + 블랙리스트 검사. 초성 표기(`ㅅㅂ`), 특수문자 삽입(`시*발`), 공백 우회(`시 발`) 패턴 포함 |
| 차단 시 응답 | "사용할 수 없는 태그입니다" 안내. 저장 거부 |
| 추후 (미정) | LLM 기반 분류로 맥락적 비하 표현까지 탐지 범위 확장 예정 |

**검색 반영 방식**

| 항목 | 내용 |
|---|---|
| ES 필드 | `user_tags` (keyword + text 분석) |
| 검색 쿼리 | `multi_match` 대상에 `user_tags` 포함. 가중치는 제목 > 공식 태그 ≥ 사용자 태그 |
| 인덱스 업데이트 | 태그 추가/삭제 즉시 `POST /{index}/_update` 로 해당 document 부분 업데이트 |

**태그 삭제**

| 항목 | 내용 |
|---|---|
| 본인 태그 | 태그 칩에 × 버튼 노출 (본인이 추가한 태그에만) |
| 타인 태그 | 삭제 불가 (관리자 모더레이션은 [FR-16](#fr-16-관리자-페이지-phase-2) 참조) |
| API | `DELETE /api/videos/{videoNo}/tags/{tag}`, `DELETE /api/clips/{clipUid}/tags/{tag}` |

## 4. Phase 2 기능 명세

> Phase 2 기능은 MVP 출시 이후 도입을 검토한다. 아래는 골격(라우팅·진입점·데이터 모델·권한) 수준의 초안이며, 화면 디자인 및 세부 인터랙션은 별도 회의에서 확정한다.

### FR-15 주제별 모아보기 (Phase 2)

**개요:** 관리자가 사전에 큐레이션한 "주제(Topic)" 단위로 VOD·클립을 묶어 사용자에게 노출한다. 단순 키워드 검색으로는 잡히지 않는 맥락 있는 묶음(예: "롤드컵 명장면", "신년 합방 정리")을 제공한다.

**라우팅 (사용자 측)**

| 경로 | 화면 | 설명 |
|---|---|---|
| `/topics` | 주제 목록 | 관리자가 공개한 주제 카드 그리드 |
| `/topics/{slug}` | 주제 상세 | 해당 주제에 속한 VOD/클립 카드 그리드 |

**진입점**
- 메인 페이지 상단 히어로 캐러셀: 추천 주제를 한 번에 1개씩 풀폭 노출, 6초 자동 순회 + 좌우 화살표/페이지 닷 조작. CTA 클릭 시 주제 상세로 이동
- 메인 페이지 캐러셀 우측 "전체 주제 보기 →" 링크로 `/topics` 진입
- 주제 상세 페이지에서 카드 클릭 시 [FR-06](#fr-06-영상-재생) 재생 흐름 그대로 사용
- **빈 상태 처리**: 공개된 추천 주제가 0개일 때는 메인 페이지의 히어로 캐러셀 섹션 자체를 노출하지 않는다 (섹션 헤딩·"전체 주제 보기" 링크 포함). 인기 클립 피드가 곧바로 최상단에 위치한다.

**토픽 커버 이미지 정책 (MVP)**

| 항목 | 내용 |
|---|---|
| 기본 동작 | 토픽에 포함된 영상의 썸네일 4개를 **자동 4분할 콜라주**로 합성하여 표시 (`videos.thumbnail_url`, `clips.thumbnail_url` 재사용) |
| 4개 미만일 때 | 가능한 만큼 분할 (1장이면 단일 표시, 2~3장이면 비대칭 그리드). 0장이면 그라데이션 + 토픽명 폴백 |
| 합성 방식 | 클라이언트 CSS 그리드로 처리 (별도 이미지 합성 백엔드 없음). `topics.cover_image_url`은 nullable로 두고 비어있으면 콜라주 렌더링 |
| 운영 부담 | 관리자는 토픽 생성 시 이미지 업로드 의무 없음. 시각적 통일성보다 운영 단순성 우선 |
| 향후 확장 | 관리자 수동 업로드 옵션 추가 검토 (오브젝트 스토리지 + 업로드 API 필요). `cover_image_url`이 채워져 있으면 콜라주 대신 해당 이미지 사용하는 형태로 자연스럽게 진화 가능 |

**데이터 모델 (초안)**

| 테이블 | 주요 컬럼 |
|---|---|
| `topics` | `id` (UUIDv7), `slug` (unique), `title`, `description`, `cover_image_url` (nullable, 비어있으면 콜라주 자동 생성), `is_published`, `created_by`, `created_at`, `updated_at` |
| `topic_items` | `topic_id` (FK), `target_type` (`vod`/`clip`), `target_id`, `display_order`, `added_at`. PK = (`topic_id`, `target_type`, `target_id`) |

> 외부 영상([FR-13](#))을 주제에 포함하는 경우는 별도 검토. 초기에는 내부 VOD/클립만 대상으로 한다.

**권한**
- 조회: 비로그인 포함 모든 사용자
- 생성/수정/삭제: 관리자 전용 ([FR-16](#fr-16-관리자-페이지-phase-2))

**향후 확장 검토**
- 사용자 큐레이션 주제 (소셜 기능)
- 태그·스트리머 기반 자동 큐레이션
- 주제 팔로우 / 알림

### FR-16 관리자 페이지 (Phase 2)

**개요:** 주제 큐레이션·사용자 태그 모더레이션 등 운영 기능을 제공하는 백오피스. 사용자 페이지와 동일한 도메인의 별도 라우팅으로 제공한다.

**라우팅 (관리자 측)**

| 경로 | 화면 | 설명 |
|---|---|---|
| `/admin` | 대시보드 | 운영 지표 요약 (디자인 미정) |
| `/admin/topics` | 주제 목록 | 주제 CRUD |
| `/admin/topics/new`, `/admin/topics/{id}/edit` | 주제 작성/편집 | 메타데이터 + 영상 큐레이션 |
| `/admin/tags` | 태그 모더레이션 | 사용자 기여 태그([FR-12](#fr-12-사용자-태그-기여)) 신고/삭제 |

**접근 제어**
- 인증: 네이버 OAuth ([FR-10](#fr-10-네이버-로그인)) 재사용
- 인가: `users.role` 또는 별도 `admin_users` 화이트리스트로 관리자 식별. 비관리자는 `/admin/*` 접근 시 403 또는 메인으로 리다이렉트
- 초기 관리자: 환경변수 또는 DB seed로 등록 (운영 절차는 [SERVER_SETUP_GUIDE.md](SERVER_SETUP_GUIDE.md) 추후 보강)

**기능 범위 (Phase 2 초기)**
- 주제 CRUD: 제목/설명/커버 이미지/공개 여부
- 주제별 영상 큐레이션: VOD/클립 검색 → 추가/제거, 순서 변경
- 사용자 태그 모더레이션: 기여 태그 목록 조회, 단건 삭제, 비속어 블랙리스트 갱신

**향후 확장 검토**
- 스트리머 관리(수동 추가/비활성화)
- 크롤 작업 모니터링 ( `crawl_jobs` 뷰)
- 운영 지표 대시보드 (검색 키워드 통계, 인기 주제 등)
- 감사 로그 (관리자 액션 기록)
