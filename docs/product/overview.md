# 치즈보드(CheeseBoard) 프로젝트 개요

## 1. 개요
- **프로젝트 명:** 치즈보드 (CheeseBoard)
- **목적:** 치지직(CHZZK)의 VOD 및 클립 컨텐츠를 조건별(스트리머, 키워드, 정렬 등)로 탐색할 수 있는 통합 검색 서비스 제공.
- **주요 타겟:** 특정 스트리머의 과거 영상을 효율적으로 찾고 싶은 유저 및 인기 클립 큐레이션 선호 유저.

## 2. 시스템 아키텍처
- **Frontend (React/TypeScript):** 검색 결과 그리드 및 필터링 UI 제공.
- **Main Backend (Spring Boot):** 비즈니스 로직, 데이터 지속성 관리(DB), 검색 API 제공.
- **Scraper Service (Python/FastAPI):** 치지직 API 연동, 데이터 수집 및 정제 마이크로서비스.

## 3. 핵심 기능
- **통합 검색:** 키워드 기반 영상 제목 검색.
- **스트리머 필터링:** 특정 채널의 VOD/클립 목록 집중 탐색.
- **스마트 정렬:** 조회수(인기순), 날짜(최신순) 기반 정렬.
- **다이렉트 링크:** 치지직 공식 영상 페이지로 즉시 연결.
